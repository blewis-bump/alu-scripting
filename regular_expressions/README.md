# Regular Expressions (Regex)

## Description
This project contains Ruby scripts that use regular expressions (Regex) to match specific patterns in strings. The exercises are part of the ALX Software Engineering curriculum and are designed to build an understanding of pattern matching and text processing.

## Learning Objectives
- Understand regular expressions and their syntax.
- Use repetition tokens such as `*`, `+`, and `?`.
- Match specific patterns in strings.
- Use Ruby's regular expression matching methods.

## Requirements
- Ubuntu 20.04 LTS
- Ruby 2.7.0 or later
- All scripts must be executable
